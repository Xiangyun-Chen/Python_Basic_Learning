# Python_Basic_Learning
This repository records my Python learning journey, from basic syntax and control flow to data analysis libraries like Pandas and Matplotlib.
# Python 学习笔记

这是我大二期间学习 Python 编程的练习记录，包含了从基础语法到数据分析的项目实践。

## 目录
|name|desription|
| :---: | :--- |
|[01_variable_and_type.py](01_variable_and_type.py)| 变量、字面量、基本数据类型及转换。|
|[02_io_operations.py](02_io_operations.py)|input 和 print 的使用及字符串操作。|
|[03_control_flow.py](03_control_flow.py)|if 条件判断、`while` 和 `for` 循环，以及 `break` 和 `continue` 控制语句的实践。|
|04_data_structures.py|介绍列表(List)的创建、访问、增删改查及遍历。|
|05_functions.py| 介绍函数的定义、参数、返回值、作用域和嵌套调用。|
|06_综合案例_ATM.py|一个结合了函数、循环和全局变量的简单ATM机模拟程序。|

## 学习目标
- 掌握 Python 基础语法。
- 为后续学习 Pandas、Matplotlib 及进行统计数据分析打下基础。
